# Bytevoice

A subscription-based, branding-first invoicing SaaS product by GrimByte Systems.

**Status:** Planning baseline — no implementation or release accepted yet.
**Baseline date:** 2026-11-24.

Bytevoice helps small businesses create and send professional, individually branded invoices with minimal effort. South African Rand (ZAR, displayed as R) is the initial default. The product is invoicing software, not an accounting suite.
